# 个人主页项目说明

## 项目简介
这是一个个人主页网站，深色科技风格，带终端动画效果，用于展示个人信息、技能和项目经历。

## 技术栈
- 原生 HTML + CSS + JavaScript
- GitHub Pages 部署

## 文件说明
| 文件 | 说明 |
|------|------|
| index.html | 主页面 |
| style.css | 样式文件 |
| app.js | 终端动画逻辑 |
| PRD.md | 需求分析文档 |
| TECH_DESIGN.md | 技术设计文档 |

## 部署方式
1. 推送到 GitHub 仓库
2. 开启 GitHub Pages
3. 访问域名即可
