# 个人主页 需求分析文档

## 一、项目背景与目标

### 1.1 项目背景
作为物联网工程专业的学生，需要一个个人主页来展示自己的学习经历、技能栈和项目作品，用于课程设计、求职准备和个人展示。

### 1.2 项目目标
开发一个深色科技风的个人主页网站，实现：
1. 首页展示个人简介和终端动画效果
2. 导航栏支持切换不同页面（关于、技能、项目等）
3. 展示个人技能和项目经历
4. 适配不同屏幕尺寸

### 1.3 项目价值
| 维度 | 价值 |
|------|------|
| 展示 | 集中展示个人信息和项目作品 |
| 专业 | 深色科技风，符合技术人员的审美 |
| 个性 | 终端动画效果，有特色 |
| 免费 | 用 GitHub Pages 免费部署 |

---

## 二、用户与场景分析

### 2.1 目标用户
- 老师、同学：查看课程设计成果
- 面试官：了解个人技术背景
- 自己：作为个人名片展示

### 2.2 典型使用场景
**场景一：课程设计提交**
> 老师要求提交个人主页，展示自己的学习成果和技术栈。

**场景二：求职展示**
> 找实习时，把个人主页链接放到简历里，让面试官快速了解自己。

## 三、功能需求分析

### 3.1 功能需求清单

#### （1）首页展示
| 编号 | 需求描述 | 必要性 |
|------|----------|--------|
| FR-01 | 深色星空背景 | 必须 |
| FR-02 | 顶部导航栏 | 必须 |
| FR-03 | 左侧个人简介区域 | 必须 |
| FR-04 | 右侧终端动画区域 | 必须 |
| FR-05 | 底部统计数据展示 | 重要 |

#### （2）终端动画
| 编号 | 需求描述 | 必要性 |
|------|----------|--------|
| FR-06 | 自动播放终端命令动画 | 必须 |
| FR-07 | 显示 whoami 命令结果 | 必须 |
| FR-08 | 显示 cat direction.txt 命令结果 | 必须 |
| FR-09 | 显示 ls skills/ 命令结果 | 必须 |
| FR-10 | 显示 git log 命令结果 | 重要 |

#### （3）导航切换
| 编号 | 需求描述 | 必要性 |
|------|----------|--------|
| FR-11 | 导航栏支持点击切换 | 必须 |
| FR-12 | 当前页面高亮显示 | 必须 |

### 3.2 功能优先级
- **Must have（MVP）**：FR-01~04、FR-06~08、FR-11~12
- **Should have（v1.1）**：FR-05、FR-09、FR-10
- **Could have（v1.2+）**：更多页面内容

## 四、界面需求分析

### 4.1 设计风格
- 深色科技风，星空背景
- 终端窗口样式，有红黄绿三个按钮
- 等宽字体，绿色代码文字
- 蓝紫渐变高亮文字

### 4.2 视觉规范
| 项 | 规范 |
|----|------|
| 背景色 | #0a0a1a |
| 主色 | #4A90D9 |
| 高亮色 | #a855f7 |
| 代码色 | #22c55e |
| 字体 | 系统 sans-serif + 等宽字体 |
